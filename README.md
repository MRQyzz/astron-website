
# ASTRON
### Astronomical Observation Network

ASTRON is an interactive astronomical exploration platform designed to
connect astronomical catalog data with SPHEREx observations.

## Project Objectives

- Explore astronomical objects through an interactive sky map.
- Retrieve astronomical catalog information.
- Search SPHEREx observation metadata and footprints.
- Retrieve and inspect FITS astronomical data.
- Present astronomical information through an integrated dashboard.

frontend and backend applications.
